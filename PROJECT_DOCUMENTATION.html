01 • System Analysis

Executive Summary

This project serves as the personal creative portfolio and independent studio presence for Rijan Shrestha, a multidisciplinary Graphic Designer, Motion Graphics Artist, and Frontend Developer based in Kathmandu, Nepal.

✦ Visual & Interaction Aesthetic

Cinematic dark palette (#0B0B0F), frosted glassmorphism overlays (backdrop-filter: blur(24px)), dual-layer interactive cursor with fine-pointer detection, physics-based magnetic attraction buttons, and Syne & DM Sans Google typography.

⚡ Architectural Finding: Monolithic Drift

The active production application compiles and executes via a single monolithic file (src/App.jsx). This file inlines its own navbars, heroes, timelines, portfolios, and footers. The parallel modular files under src/components/sections/ and src/components/layout/ exist in the repository but are completely unreferenced.

Evolutionary Progression of the Codebase

Phase 1
Static HTML Prototypes

Standalone vanilla JS prototypes (index-old.html, index-react.html) with Bebas Neue typography.

Phase 2
Burgundy React Prototype

Initial React iteration with burgundy accents (#6D001A), floating bubbles, and older GSAP hooks in src/App-old.jsx.

Phase 3
Modular Scaffolding

Creation of discrete section components in src/components/sections/ and shared mock dataset in src/data/projects.js.

Phase 4 (Current)
Monolithic Production

Consolidation into src/App.jsx featuring interactive 3D physics tilt, masonry layout, and Lenis scroll engine.

05 • Feature Analysis

Interactive Feature Breakdown & Sandboxes

Technical evaluation of the 6 primary interaction mechanics running on the portfolio, paired with live functional sandboxes.

Preloader Screen Architecture

Located at src/components/ui/Preloader.jsx. Uses a sequenced GSAP timeline that blocks user interaction until critical fonts and assets initialize, preventing unstyled layout shifts (CLS).

  • Phase 1: Scale-in and opacity fade for the RS studio badge (600ms).
  • Phase 2: Numeric counter interpolates 0 → 100% alongside horizontal progress bar.
  • Phase 3: Screen splits vertically into top (yPercent: -100) and bottom (yPercent: 100) blinds.
  • Callback: onComplete() triggers setIsLoaded(true) in App.jsx to fire hero entrances.

Dual-Layer Spring Cursor

Located at src/components/ui/Cursor.jsx. Operates with strict accessibility gates: checks window.matchMedia('(pointer: fine)').matches to completely self-disable on touchscreens and mobile devices.

  • Inner Dot: Zero-latency mouse coordinates via mousemove listener.
  • Trailing Ring: GSAP spring easing (duration: 0.15s, ease: 'power2.out').
  • Hover Expansion: Expands and applies translucent accent glow when hovering interactive targets (a, button, [data-cursor-hover]).

Lenis Momentum Scroll Engine

Located at src/hooks/useLenis.js. Integrates Studio Freight's Lenis scroll engine into React via requestAnimationFrame.

src/hooks/useLenis.js
const lenis = new Lenis({
  duration: 1.1,
  smoothWheel: true,
  smoothTouch: false,
  lerp: 0.08,
})

A lerp parameter of 0.08 delivers heavy, cinematic inertia suitable for luxury portfolios while leaving touch scrolling native on mobile to preserve 60fps responsiveness.

Character Stagger (SplitText)

Located at src/components/ui/SplitText.jsx. Parses headline strings into individual character nodes (.char), non-breaking spaces, or word spans to allow staggered physics entrances.

SplitText Logic in App.jsx
gsap.utils.toArray('.split-heading .char').forEach((char) => {
  gsap.from(char, {
    opacity: 0,
    y: 18,
    duration: 0.7,
    ease: 'power3.out',
    scrollTrigger: { trigger: char, start: 'top 90%' }
  })
})
